About this linter. It checks the structural rules of the Agent Skills format (SKILL.md): YAML frontmatter with a valid name and description, description length and leading-trigger convention, total file size, and common anti-patterns that break real agent skills (vague steps, restating defaults, "optional" waffling). It's a heuristic guide, not a hard gate — a clean skill can still be wrong for its job.
